PairPulse 0.2.2 user guide

SCOPE AND CONVENTIONS
The package implements two-component Dirac and three-variable quantum-kinetic evolution in one spatial dimension for a prescribed homogeneous fixed-axis field. Natural units are used; pi=p-q*A and E=-dA/dt. Occupations are per channel. Density uses dp/(2*pi), with no transverse integral or extra spin factor. No back-reaction, collisions, arbitrary polarization or opposite-polarity built-in pulse train is supplied. Custom consistent fields may have either polarity. Finite-time occupations use the stated instantaneous basis.

INSTALLATION AND REPRODUCTION
Create/activate a virtual environment and run the following commands from Computational_materials. Requirements files are exact pins, not lower bounds; the core metadata separately declares lower bounds. The pinned environment requires Python >=3.11, while the core declares >=3.10. Only Python 3.13.9 was tested for this revision.

NUMERICAL CONTROLS
The default DOP853 tolerances are rtol=2e-10 and atol=2e-12. The phase step cap is max_step_coefficient/max_frequency (default coefficient 0.18). The sampled frequency estimate is not a mathematical upper bound. Built-in Sauter profiles additionally cap steps at duration/8; pulse trains use the shortest active duration. A positive finite max_step can impose a stricter absolute cap. Custom pulses implement field(t), potential(t), time_window(tail_factor), and preferably resolution_scale(). Without a feature scale or explicit cap the solver warns: a narrow feature can be missed while a norm or invariant remains excellent. Time windows must be finite and increasing.

The stable Sauter expression uses rationalized energy gaps, logarithmic scaling and expm1 factors. sauter_log_occupation returns -infinity for zero field and retains finite logs for underflowed probabilities. sauter_exact_occupation returns the floating-point probability. Inputs whose kinematics cannot be represented raise an error; this is not an arbitrary-precision solver.

integrated_density sorts finite nodes and rejects duplicates. With check_bounds=True it also enforces occupations within [0,1], allowing bounds_tolerance=1e-10 by default. Small tolerated negative values are not clipped. Increase the momentum range separately from refining spacing. Tolerances, caps and endpoints also need independent refinement. The double-pulse validation uses two pulses with E0=0.3, tau=1.1 and centers -3.5,+3.5; pulse_spec records each component exactly.

EVIDENCE AND LIMITS
